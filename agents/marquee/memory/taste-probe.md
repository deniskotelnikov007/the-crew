# Taste probe

Well-known titles chosen to test specific parts of our taste. Ask them one at a time.
- **Seen:** log the scores and a one-line reason in `watched.md`, then mark the row `done`.
- **Not seen:** mark it `not seen`. Mark it `curious` if either of us wants to watch it; that makes it a candidate for picks.
